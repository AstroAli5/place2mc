Get a place's data for place2mc

This page downloads, in your own browser, everything place2mc needs to build the place exactly: the map from OpenStreetMap, and the US government's laser scan of it (USGS 3DEP LiDAR), which measures the ground, the top of every roof and every tree to a few centimetres. It boils the scan down to one small file. Then attach that file in the chat.

Save the file

Takes a few minutes and downloads about 60 MB.

Map data © OpenStreetMap contributors (ODbL). Laser scan: U.S. Geological Survey 3D Elevation Program (public domain). LAZ decoding: laz-perf by Hobu, Inc. (Apache-2.0). Nothing is sent anywhere except the requests for this data; the file is made on your computer.
