# Pixel Perfection CE textures

These are block textures from **Pixel Perfection CE** (https://github.com/Athemis/PixelPerfectionCE, commit
28e38cab7c1f), the community edition of **Pixel Perfection** by Hugh "XSSheep" Rutland,
with updates by the Pixel Perfection CE contributors listed in that repository.

They are licensed under the Creative Commons Attribution-ShareAlike 4.0 International License (LICENSE.md,
https://creativecommons.org/licenses/by-sa/4.0/). place2mc includes only the block textures it draws, unchanged,
so that its pictures and its walk-through look like Minecraft on computers without the game. If you change
them, share your changes under the same licence.

They are not Mojang textures. When Minecraft Java is installed, place2mc uses the textures of your own copy instead.
